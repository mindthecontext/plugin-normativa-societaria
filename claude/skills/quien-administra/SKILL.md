# Quién administra la sociedad

Responde **de dónde sale la administración y la representación** de una sociedad y **quién puede otorgar poderes**.
Puede ser con el estatuto del caso o en abstracto («en una limitada, si la escritura no designa…»).

Lee primero `references/criterio-de-respuesta.md`, sección «La cadena del tipo social».

## Pasos

1. **Tipo y régimen.** Si no se dan, pregúntalos o responde para cada tipo relevante. Si el tipo no está cubierto,
   dilo.
2. **`cadena_del_tipo`** con tipo y régimen. Lee con `ver_articulo` cada artículo que vayas a citar.
3. **Si hay estatuto**, cita el pasaje que regula la administración. Ese eslabón manda. Para cada punto que el
   estatuto calla, aplica el siguiente eslabón con las tres comprobaciones, dichas.
4. **Sin estatuto** (pregunta en abstracto): explica la cadena y la regla por defecto de cada eslabón, y advierte que
   el estatuto puede cambiarla y que, en concreto, hay que leerlo.
5. **Quién otorga poderes y cómo**: órgano, formalidad (acta reducida a escritura, escritura de mandato, formulario
   del RES) y dónde constan, según el régimen.
6. **El cargo no acredita facultades** más allá de lo que la ley le asigna: dilo cuando la pregunta suponga lo
   contrario.

## Formato

```
Respuesta corta: <quién administra, quién representa, quién otorga poderes>
Cadena aplicada
1. <eslabón> · <pasaje del estatuto o artículo con versión> · <qué resuelve aquí>
2. ...
Lo que el estatuto debe decir para cambiar esto
Lo que falta acreditar (si hay caso)
Normas aplicadas (corpus societario-corpus-2026-10-28)
Límites (reglas provisionales: C.1, C.2, C.3 si aplican)
```

Esta skill no tiene estado de tres valores salvo que la pregunta sea si alguien concreto administra o representa: en
ese caso, termina con «Estado» como `quien-puede-firmar`.
